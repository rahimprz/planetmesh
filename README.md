# Planet Mesh — landing page (React + GSAP)

## Run locally
npm install
npm run dev

## Deploy
npm run build   → upload the `dist/` folder to your host
(Vercel / Netlify: import the folder, build command `npm run build`, output `dist`.)

## Edit content
All text and links live in `src/content.js`.
Each section is a component in `src/components/`.
